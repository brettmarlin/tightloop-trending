# Tightloop trending

The public selection criteria for the 48-hour reading list in the Tightloop Discord's #whats-trending channel.

- [TRENDING-CRITERIA.md](TRENDING-CRITERIA.md) explains what gets picked and why.
- Want to change how items are picked? Open a pull request against that file. Brett reviews and merges.

This repo holds only the criteria. The lists themselves are posted in Discord.
